# FIX12 彩種初始化與名稱統一 - 2026-01-10

## 問題描述

1. 建立集資時彩種選項為空
2. 名稱不統一（系列團/集資團）需全部改為「集資」
3. 每次建立集資只能選一種彩種，份額單位需對應彩種價格

## 修復內容

### 1. Dockerfile - 添加 seed_data.py 執行

啟動時執行彩種初始化腳本，確保 lottery_types 資料表有資料。

### 2. app/main.py - 註冊 lottery_types router

```python
from app.api.v1.lottery_types import router as lottery_types_router
application.include_router(lottery_types_router, prefix="/v1")
```

### 3. 名稱統一修改

所有「系列團」「集資團」統一改為「**集資**」

#### dashboard.html 修改

| 原本 | 修改後 |
|------|--------|
| 參與團數 | 參與集資 |
| 我的系列團 | 我的集資 |
| 加入系列團 | 加入集資 |
| 加入或建立系列團開始吧! | 加入或建立集資開始吧! |

#### wallet.html 修改

| 原本 | 修改後 |
|------|--------|
| 系列團份額 | 集資份額 |
| 尚未參與任何系列團 | 尚未參與任何集資 |

#### series.html 修改

| 原本 | 修改後 |
|------|--------|
| 我的系列團 / 我的集資團 | 我的集資 |
| 建立系列團 / 建立集資團 | 建立集資 |
| 系列團名稱 / 集資團名稱 | 集資名稱 |
| 還沒有加入任何系列團 | 還沒有加入任何集資 |
| 建立一個新的系列團 | 建立一個新的集資 |
| 請輸入系列團名稱 | 請輸入集資名稱 |
| 系列團建立成功 | 集資建立成功 |
| 成功加入系列團 | 成功加入集資 |

#### series-detail.html 修改

| 原本 | 修改後 |
|------|--------|
| 系列團詳情 | 集資詳情 |
| 系列團 | 集資 |

### 4. series.html - 彩種改為單選

- 從 checkbox（多選）改為 radio button（單選）
- 每個集資只能選擇一種彩種
- 份額單位根據彩種動態調整

| 彩種 | 每注價格 | 份額單位 | 預設值 |
|------|----------|----------|--------|
| 威力彩 | 100 元 | 100 | 500 元 |
| 大樂透 | 50 元 | 50 | 250 元 |
| 今彩539 | 50 元 | 50 | 250 元 |

- 驗證：份額必須是彩種價格的倍數

## 測試驗證

### 彩種初始化
1. 部署後檢查啟動 log，應該看到：
   - `🔑 初始化彩種資料...`
   - `✅ 威力彩 已建立`
   - `✅ 大樂透 已建立`
   - `✅ 今彩539 已建立`

### 名稱統一
1. 儀表板：確認「參與集資」「我的集資」「加入集資」
2. 錢包：確認「集資份額」
3. 集資頁面：確認所有文字為「集資」

### 單選彩種
1. 進入「我的集資」頁面
2. 點擊「建立集資」
3. 確認彩種為單選（radio button）
4. 選擇威力彩 → 確認份額單位變為 100
5. 選擇大樂透 → 確認份額單位變為 50
6. 輸入非倍數金額 → 確認顯示錯誤提示
7. 成功建立集資 → 確認只有一種彩種標籤
