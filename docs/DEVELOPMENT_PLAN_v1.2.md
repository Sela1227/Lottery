## Phase 1：成員異動功能 ✅ 開發包已準備

> **目標**：完善成員管理機制，支援減碼與退出
> **模式**：統一採用彈性模式（所有集資都支援減碼/退出）

### 1.1 減碼申請

| 項目 | 說明 |
|------|------|
| **功能** | 成員申請減少份額 |
| **限制** | 減碼後至少保留 50 元 |
| **流程** | 申請 → 管理員審核 → 執行減碼 → 記錄帳本 |

### 1.2 退出申請

| 項目 | 說明 |
|------|------|
| **功能** | 成員申請退出集資 |
| **條件** | 管理員無法退出（需先轉移權限） |
| **流程** | 申請 → 管理員審核 → 結算份額 → 移除成員 |

### 1.3 申請審核

| 項目 | 說明 |
|------|------|
| **功能** | 管理員審核減碼/退出申請 |
| **操作** | 核准 / 拒絕（可填原因） |
| **結果** | 核准後自動執行、記錄帳本 |

### API 端點

| 方法 | 路徑 | 說明 |
|------|------|------|
| POST | `/member-requests/series/{id}/reduce` | 申請減碼 |
| POST | `/member-requests/series/{id}/withdraw` | 申請退出 |
| POST | `/member-requests/{id}/cancel` | 取消申請 |
| GET | `/member-requests/my` | 我的申請 |
| GET | `/member-requests/series/{id}` | 集資所有申請 |
| POST | `/member-requests/{id}/review` | 審核申請 |

## Phase 2：個人彩券系統

> **目標**：提供完全私密的個人彩券記錄功能

### 2.1 個人彩券記錄

| 項目 | 說明 |
|------|------|
| **功能** | 記錄個人購買的彩券（非團購） |
| **隱私** | 完全私密，僅本人可見 |
| **欄位** | 彩種、期數、號碼、購買金額、購買日期 |

### 2.2 個人彩券新增

| 項目 | 說明 |
|------|------|
| **功能** | 新增個人彩券記錄 |
| **選號** | 支援手選 / 電腦選號 |
| **批量** | 支援一次新增多組號碼 |

### 2.3 個人彩券對獎

| 項目 | 說明 |
|------|------|
| **功能** | 自動比對開獎號碼 |
| **觸發** | 開獎後自動對獎 / 手動觸發 |
| **結果** | 顯示中獎等級、獎金金額 |

### 2.4 個人彩券統計

| 項目 | 說明 |
|------|------|
| **功能** | 個人投注統計分析 |
| **指標** | 總投注、總中獎、投報率、常選號碼 |

### 2.5 個人彩券列表

| 項目 | 說明 |
|------|------|
| **功能** | 查看所有個人彩券記錄 |
| **篩選** | 彩種、期數範圍、中獎狀態 |

## Phase 3：錢包與金流管理

> **目標**：完善錢包功能，支援充值與提領

### 3.1 錢包餘額系統

| 項目 | 說明 |
|------|------|
| **優化** | 區分「可用餘額」與「鎖定金額」 |
| **類型** | 可用餘額、鎖定金額、集資份額 |

### 3.2 銀行帳戶管理

| 項目 | 說明 |
|------|------|
| **功能** | 用戶綁定銀行帳戶 |
| **欄位** | 銀行代碼、分行、帳號、戶名 |
| **限制** | 每人最多綁定 3 個帳戶 |

### 3.3 充值功能

| 項目 | 說明 |
|------|------|
| **功能** | 用戶申請充值到錢包 |
| **流程** | 申請 → 轉帳 → 上傳憑證 → 審核 → 入帳 |

### 3.4 提領功能

| 項目 | 說明 |
|------|------|
| **功能** | 用戶申請提領錢包餘額 |
| **流程** | 申請 → 審核 → 轉帳 → 完成 |
| **限制** | 單次最低 100 元 |

### 3.5 轉帳功能

| 項目 | 說明 |
|------|------|
| **功能** | 錢包餘額轉入集資份額 |
| **反向** | 集資份額轉回錢包（需審核） |

### 3.6 交易記錄查詢

| 項目 | 說明 |
|------|------|
| **功能** | 查看所有錢包交易記錄 |
| **類型** | 充值、提領、轉帳、獎金入帳 |
