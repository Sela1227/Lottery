## 🛠️ 設定步驟

### 1. 申請 LINE Notify 服務

1. 前往 [LINE Notify](https://notify-bot.line.me/my/services/) 管理頁面
2. 點擊「登錄服務」
3. 填寫服務資訊：
   - **服務名稱**: SELA 樂透一路發
   - **服務網址**: `https://你的網域.railway.app`
   - **Callback URL**: `https://你的網域.railway.app/api/v1/notify/callback`
4. 取得 `Client ID` 和 `Client Secret`

### 2. 設定環境變數

在 Railway 加入以下環境變數：

```env
LINE_NOTIFY_CLIENT_ID=你的_Client_ID
LINE_NOTIFY_CLIENT_SECRET=你的_Client_Secret
```

### 3. 執行資料庫遷移

```bash
python scripts/migrate_notify.py
```

或在 Railway 中執行。

## 📡 API 端點

| 方法 | 路徑 | 說明 |
|------|------|------|
| GET | `/api/v1/notify/settings` | 取得通知設定 |
| PUT | `/api/v1/notify/settings` | 更新通知設定 |
| GET | `/api/v1/notify/line/connect` | 開始 LINE Notify 連結 |
| GET | `/api/v1/notify/callback` | LINE Notify 授權回調 |
| POST | `/api/v1/notify/line/disconnect` | 解除 LINE Notify 連結 |
| POST | `/api/v1/notify/test` | 發送測試通知 |

## 📱 用戶操作流程

### 連結 LINE Notify

```
設定頁面 → 點擊「LINE Notify」
    ↓
跳轉 LINE 授權頁面
    ↓
用戶同意授權
    ↓
回調處理，儲存 token
    ↓
發送歡迎訊息
    ↓
返回設定頁面（顯示「已連結」）
```

### 通知設定

連結成功後，用戶可以：
- 開關「開獎提醒」
- 開關「中獎通知」
- 開關「結算通知」
- 發送測試通知
- 解除 LINE Notify 連結
