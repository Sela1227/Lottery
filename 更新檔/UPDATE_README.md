## ✨ 功能說明

### 💰 錢包概覽
- 總資產（錢包餘額 + 團購份額）
- 錢包餘額顯示
- 團購份額總計
- 參與系列團數量

### 📊 統計數據
- 累計投資金額
- 累計獎金收入

### 🎰 系列團份額
- 各系列團份額明細
- 佔比百分比
- 點擊可跳轉至系列團

### 📋 交易記錄
- 全部交易記錄
- 可篩選：全部 / 團購 / 獎金
- 顯示交易類型、金額、時間
- 支援載入更多

## 🔗 新增 API 端點

| 方法 | 路徑 | 說明 |
|------|------|------|
| GET | `/api/v1/wallet/overview` | 錢包概覽 |
| GET | `/api/v1/wallet/pool-shares` | 各系列團份額 |
| GET | `/api/v1/wallet/transactions` | 交易記錄列表 |
| GET | `/api/v1/wallet/transactions/summary` | 交易統計摘要 |

### 交易記錄篩選參數

| 參數 | 說明 | 範例 |
|------|------|------|
| `account_type` | 帳戶類型 | `wallet`, `pool` |
| `transaction_type` | 交易類型 | `pool_prize`, `pool_topup` |
| `series_id` | 系列團 ID | `1` |
| `skip` | 跳過筆數 | `0` |
| `limit` | 每頁筆數 | `20` |

## 🎨 儀表板變更

- 新增「我的錢包」快速操作按鈕（綠色）
- 移除「個人彩券」按鈕（改為錢包）
- 按鈕排列更新：
  1. 🎰 我的系列團（橘色）
  2. 💰 我的錢包（綠色）✨新增
  3. 🎫 加入系列團
  4. 📊 統計報表
  5. 🔧 管理後台（紫色，僅管理員）

## 📱 使用方式

1. 登入後點擊儀表板的「💰 我的錢包」
2. 或直接訪問 `/wallet`
3. 可查看資產概覽、系列團份額、交易記錄

## ⚠️ 注意事項

- 交易記錄來自 `user_ledger` 表
- 需要有加入系列團、加碼等操作才會產生記錄
- 目前為只讀功能，儲值/提領功能待後續開發
